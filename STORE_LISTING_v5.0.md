AutoFlow — Batch Video & Image Generator for Google Flow

AutoFlow is a productivity side panel for Google Flow (labs.google/flow). Queue hundreds of prompts, pick your model, click Run — and let AutoFlow drive Flow for you. In v5.0 it also includes Studio, a visual workflow builder for chaining prompts, reference images and generations together.

Built for content creators, marketers, animators and anyone producing AI video at volume.

⚡ AUTOFLOW STUDIO — VISUAL WORKFLOW BUILDER
Build a workflow on a canvas instead of a list. Connect a prompt to a generation, feed that result into the next one, and run the whole chain in one click.

• B-roll packs — batch several cutaways in a single run
• ChatGPT support — design an image on ChatGPT, then animate it on Flow
• Save, reload, import and export workflows as JSON

🎬 CORE FEATURES
━━━━━━━━━━━━━━━━━━━━━━━━━

BATCH PROMPT QUEUE
Paste 1 to 2,000+ prompts at once. Each becomes its own generation task. AutoFlow types the prompt, applies every setting, clicks Generate, waits for completion, then moves to the next — hands-free.

THREE AUTOMATION MODES
• FULL — creates a new project, fills every field, runs unattended
• FLOW — runs inside your current Flow session for maximum control
• LITE — pastes prompts only; you drive the rest

ALL CURRENT FLOW MODELS
• Omni Flash — high-speed video, supports 10-second clips
• Veo 3.1 Quality / Fast / Lite — choose fidelity vs speed
• Nano Banana Pro / Nano Banana 2 — fast image models
• Imagen 4 — high-detail image generation

DURATION, RATIO & COUNT
Set clip length (4s, 6s, 8s, 10s), aspect ratio (16:9 or 9:16) and generations per prompt. Change any of it inline on the queue card — no trip back to Settings.

REFERENCE IMAGES & FRAME CHAINS
• Attach reference images per prompt, or share them across a whole queue as ingredients
• Frame-to-Video: upload N images to generate N-1 seamless transitions from consecutive start/end frames
• The backbone of character-consistent content

VOICE CHARACTERS
Assign a voice ingredient so narration stays consistent across clips.

QUEUE MANAGEMENT
• Multiple named queues, each with its own configuration
• Inline editing of model, duration, ratio and generations
• Reorder queues, or sync one to your current Settings in a click
• Pause, resume, stop, skip, and retry failed prompts
• Live progress and run logs

BATCH DOWNLOAD & LIBRARY SCANNER
• Auto-download video in 720p, 1080p upscaled or 4K
• Auto-download images in 1K, 2K or 4K
• Browse your full Flow output history, filter and search it
• See which model and prompt produced each asset
• Bulk-select and download in one go

SMART RETRY & ERROR HANDLING
Failed generations are flagged with a readable reason, retryable individually or in bulk, with optional auto re-prompt and configurable stop-on-error.

MULTI-LANGUAGE
Interface in English, العربية, Français and Español. AutoFlow also recognises Google Flow's own interface in 13 languages, so automation keeps working whatever language Flow is displayed in. Your prompts are never translated.

ADVANCED SETTINGS
Wait times between prompts, variable-speed typing, human-like interaction pacing, and completion notifications with optional sound.

🔒 PRIVACY
━━━━━━━━━━━━━━━━━━━━━━━━━

• Your prompts, queues, images and settings are stored locally in your browser
• Prompt text is never sent to AutoFlow's servers. Our backend receives only counts — how many prompts you ran — to enforce plan limits
• Two optional features do send prompt text to a third party, and only when you turn them on: AI Assist (to Google Gemini, using your own API key) and ChatGPT workflow nodes (to chatgpt.com, using your own logged-in session)
• AutoFlow runs only on Google Flow (labs.google/flow), and on chatgpt.com if you use a ChatGPT node
• No tracking, no analytics, no third-party data sharing
• An AutoFlow account is required, so plan limits can be applied to your usage
