## Store listing tab

### Description

```
AutoFlow Studio turns AI video generation into a workflow you can see.

Instead of pasting prompts one at a time and babysitting each tab, you lay your project out on a visual canvas — one node per step — connect the steps, and press Run. Studio coordinates your generation tools directly in your browser using your existing signed-in sessions.

WHAT YOU BUILD WITH

• Prompt — a shot description, written by you or generated by an assistant
• Image — reference visuals and concept stills that feed downstream video generations
• Generate — sends prompts to video generation tools and waits for the finished render
• Last Frame — captures the final frame of one clip so the next clip continues seamlessly
• Extend — lengthens existing video clips into longer takes
• Story — describe your vision once, and Story creates a synchronized shot list while maintaining consistent character identity, wardrobe, setting, and lighting across scenes
• Agent — delegates creative reasoning, scriptwriting, or prompt polishing to AI assistants and routes the output to subsequent steps

DESCRIBE IT AND LET IT BUILD

Type what you want in plain language — such as "a 6-shot commercial for a ceramic mug with cinematic table lighting" — and the built-in natural language engine constructs the workflow for you. You can also attach a reference image to build around specific visual styles.

CONTINUITY THAT HOLDS

Multi-shot videos often struggle when subsequent cuts forget the character or environment. Story Director locks the cast, wardrobe, camera motion, and visual presets throughout the entire sequence. Last Frame stitching links clips together so physical motion continues smoothly instead of resetting.

NO API KEYS NEEDED

Studio operates directly through standard web interfaces in your own browser tabs. You never need to manage, paste, or fund third-party developer API keys.

PRIVACY & LOCAL STORAGE

Your workflows, prompts, node configurations, and reference frames stay saved locally in your browser storage. Your data remains on your machine unless you explicitly choose to export or publish a workflow template.

PRICING

• Free — 10 workflow runs per month, access to all node types, no credit card required.
• Pro — $9.99 per month for unlimited workflow runs.

NOT AFFILIATED

AutoFlow Studio is an independent productivity extension and is not affiliated with, endorsed by, or sponsored by any third-party AI model providers. All trademarks belong to their respective owners.

Support and documentation: https://auto-flow.studio
```

## Privacy tab

### Single purpose

```
AutoFlow Studio provides one thing: a node-based canvas for building and running multi-step AI video workflows across the web interfaces of AI sites the user is already signed in to. Every permission below exists to drive those pages and to keep a long-running workflow alive until it finishes.
```

### Permission justifications

**sidePanel**

```
The workflow canvas, the builder and the run log live in Chrome's side panel so they stay visible beside the site being automated. This is the extension's primary interface — without it there is nowhere to build a workflow.
```

**storage**

```
Stores the user's saved workflows, node settings and their AutoFlow sign-in token locally in the browser.
```

**unlimitedStorage**

```
Workflows carry reference images and extracted video frames inline as data URLs. A few storyboards exceed the default 5MB quota, which would silently drop the user's saved work.
```

**activeTab**

```
When the user starts a run from the toolbar, Studio acts on the tab they are currently looking at rather than guessing which tab to drive.
```

**scripting**

```
Attaching a reference image to an AI chat composer requires dispatching paste and drop events in the page's own JavaScript context. A content script runs in an isolated world and cannot reach the page's framework handlers, so the attachment step is injected into the MAIN world. This is the only use.
```

**alarms**

```
A video render takes minutes. MV3 suspends the service worker long before that. An alarm re-wakes the worker so it can keep polling a run that is still in progress; without it Chrome kills the worker mid-workflow and the user's run is lost.
```

**identity**

```
Powers "Sign in with Google" for the user's AutoFlow account. Only the resulting ID token is used, and only against our own backend at api.auto-flow.studio.
```

**Host permissions**

```
One entry per site the extension automates, each backed by a content script:

labs.google — Google Flow, where video is generated
chatgpt.com, gemini.google.com, claude.ai, grok.com, chat.z.ai — the chat sites an Agent node can delegate a step to
api.auto-flow.studio — our own backend, for sign-in, plan and run counting
localhost / 127.0.0.1 — optional local connectivity for users who run local AI engines (e.g. ComfyUI) alongside their browser workflows

They are listed individually rather than as a broad pattern. The extension does not run on any other page.
```

**debugger**

```
Used exclusively for Chrome DevTools Protocol (CDP) file chooser interception. When a workflow needs to upload a video clip or reference image to Google Flow's composer, the native file picker dialog blocks automation entirely — no script can interact with it. The debugger permission lets the extension intercept the file chooser event via CDP and programmatically provide the file, completing the upload without user intervention. This is the only use of the debugger API.
```

**downloads**

```
Works together with the debugger permission above. To upload a video file to Google Flow via CDP file chooser interception, the file must first exist on disk. The downloads permission saves a temporary copy, the CDP handler provides it to the file picker, and the extension immediately deletes the temporary file afterward. No other downloads are initiated.
```

**Remote code**

```
No. All code is contained in the package. The extension does not load or execute any script fetched at runtime.
```

## Expect questions on

Six host permissions across six AI sites, plus `scripting` with MAIN-world
injection, is the slowest review lane there is. Reviewers ask two things:

1. **Why run on all six?** The Agent node lets the user pick which assistant
   handles a step, and each site needs its own adapter because each composer is
   different.
2. **What does the MAIN-world injection do?** Attaches an image file to a
   composer, nothing else. Point at the exact function.

Neither is disallowed. Both are slow if the justification is thin, so keep the
wording above rather than shortening it.
